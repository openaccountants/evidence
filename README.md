# OpenAccountants evidence

This repository holds the proof behind the figures in the OpenAccountants tax skills
([openaccountants/openaccountants](https://github.com/openaccountants/openaccountants)):
snapshots of the official source pages each figure was checked against, and the ledgers
that tie each figure in a skill to the source line it came from.

It is not a set of skills. Nothing here is tax advice, and nothing here has been
approved by an accountant unless a file says so by name.

## How it is organised

| Folder | What it holds |
|---|---|
| `ledgers/` | Per-country and per-skill ledgers: the rows each skill relies on, the official source for each row, captured source pages, preservation and review records |
| `research/` | Country research records: what was read, when, and the limits of each read |
| `oman-2026-closeout/`, `uae-2026-closeout/` | Close-out records for the 2026 Oman and UAE packs |
| `malta-deep-audit-20261104/` | The 4 November 2026 Malta audit: correction ledgers per skill |
| `malta-professional-approval-20261105/` | The 5 November 2026 Malta approval record |
| `burkina-faso-remaining-20261101/`, `burkina-faso-vat-social-20261101/` | Burkina Faso source records, 1 November 2026 |
| `quarantine/` | Material held back from the skills until it is checked |

Paths here are the same as they were under `evidence/` in the main repository, minus the
`evidence/` prefix. A link that used to read `evidence/ledgers/x/y.md` is now
`https://github.com/openaccountants/evidence/blob/main/ledgers/x/y.md`.

## Snapshot and what comes next

This is a snapshot of the main repository's `evidence/` folder as of 17 November 2026
(main at commit `19cdaa46`). The folder's earlier history stays in the main repository's
git history. From this date, new evidence goes here, not into the main repository.
